# 프론트 디자인·구현 요청문

아래 요청문은 이 프로젝트의 코딩 에이전트에 그대로 전달할 수 있다. v0 같은 외부 도구에서도 화면 초안 요청으로 사용할 수 있으나, 로컬 스킬은 이 프로젝트에서만 제공된다. Google Stitch는 사용하지 않는다.

---

자기소개서 기반 AI 면접 연습과 실시간 AI 발표 심사 서비스를 디자인하고 프론트를 구현해줘. 프로젝트 AGENTS.md와 관련 디자인 스킬을 읽고, 한 달짜리 교내 경진대회에서 시연할 수 있는 범위로 진행해줘.

Next.js, TypeScript, Tailwind CSS, shadcn/ui를 기본 후보로 삼되 기존 코드가 있으면 먼저 확인해줘. 기존 앱이 없으면 프론트 초안을 만들고, 백엔드가 없는 기능은 명시적인 데모 상태로 구현해줘.

필요한 화면:
1. 홈: 면접 연습과 발표 연습을 별도 선택. 각 모드의 준비물과 진행 방식을 짧게 설명.
2. 면접 준비: 자기소개서·이력서 업로드, 추출 내용 확인, 희망 직무, 난이도, 연습 시간, 마이크 점검.
3. 면접실: 현재 질문, 면접관 음성 상태, 내 마이크 상태, 실시간 자막, 남은 시간, 일시정지·종료. 답변 이후 꼬리 질문이 이어지는 데모 흐름.
4. 발표 준비: 발표 자료 업로드, 주제와 목표 시간, 질문 강도, 마이크 점검.
5. 발표실: 발표 자료가 중심이며 질문·반박이 발생하면 보조 패널로 표시. 질문 답변 후 발표 재개가 분명한 흐름.
6. 결과: 발언 근거와 연결된 피드백, 잘한 점, 개선할 점, 질문별 다시 연습. 검증되지 않은 점수를 객관적 평가처럼 표현하지 말 것.

화면은 한국어로 작성해줘. 중립적인 배경에 절제된 강조색, 명확한 타이포 계층과 넉넉한 여백을 사용하고, 실제 연습 화면에 집중할 수 있게 구성해줘. 공통 디자인 토큰과 재사용 컴포넌트를 먼저 정리해 화면 사이 일관성을 유지해줘. 모바일에서도 준비·결과를 읽을 수 있게 하되 실시간 연습은 데스크톱을 우선해줘.

업로드 중·실패·빈 화면, 마이크 권한 거부, 연결 끊김, 재접속, 세션 종료 확인을 포함해줘. 키보드 접근성, 자막, 대비, 모션 감소를 반영해줘. 실제 음성 API가 연결되지 않았다면 작동 중인 것처럼 속이지 말고 데모 제어를 제공해줘.

완료 후 실제 브라우저로 주요 흐름을 확인하고, 구현된 것과 아직 연결되지 않은 것을 알려줘.
