# 리허설

자기소개서 기반 AI 면접과 발표 심사 연습을 제공하는 한국어 웹 앱. 두 모드의 준비 화면과 진행 흐름을 분리하고, 연습 뒤 답변 근거를 담은 피드백을 제공한다.

## 실행

Node.js 22 이상과 pnpm을 사용한다.

```sh
pnpm install
pnpm dev
```

기본 주소는 http://localhost:3000 이다. `.env.example`을 `.env.local`로 복사하고 서버 전용 `OPENAI_API_KEY`를 설정한다. 키 없이도 데모 모드를 이용할 수 있다. 키를 소스·브라우저·채팅에 복사하지 않는다. 설정 이름은 `.env.example` 참조.

```sh
pnpm typecheck
pnpm lint
pnpm build
pnpm start
```

이 환경의 Turbopack은 외부 codegraph 경로와 충돌하여 검증된 Webpack 실행 옵션을 사용한다.

## 기능

- 면접: 자기소개서·지원 분야에 근거한 질문과 답변 기반 꼬리 질문.
- 발표: 자료·발언에 대한 질문과 반박. 실시간 음성에서는 강도별 25/45/75초 주기로 질문을 시도하며 AI가 이미 말하는 경우 건너뛴다. 수동 질문도 가능하다.
- PDF(80쪽 이하), DOCX, PPTX, UTF-8 TXT 텍스트 추출. 파일 최대 10MB, 텍스트 최대 30,000자. 스캔 이미지 OCR과 슬라이드 시각 분석은 포함하지 않는다.
- WebRTC 실시간 음성, 한국어 자막, 마이크 일시 정지, AI 발화 중단. 브라우저 마이크 권한과 localhost 또는 HTTPS가 필요하다.
- 텍스트 질문·답변, 일시 정지, 연습 시간, 리포트, 실제 답변 원문 근거, Markdown 내보내기.
- 브라우저에 최근 30개 기록 보관, 새로고침 복원, 모드 필터와 삭제.
- 키가 필요 없는 데모. 고정 질문·안내 피드백임을 모든 화면에 표시하며 실제 AI 실패를 데모 응답으로 대체하지 않는다.

음성은 세션 시작 시 선택한다. 음성을 끄면 자막을 바탕으로 텍스트 연습을 이어갈 수 있다. 텍스트로 진행하던 세션에서 음성을 새로 연결하지 않도록 제한하여 대화 맥락이 초기화되는 혼란을 방지한다.

## 실제 API 상태와 범위

2026-10-20 실제 질문 요청은 OpenAI에서 429(사용 한도/잔액)를 반환했다. 따라서 실제 모델 질문 품질·음성 대화의 성공은 아직 검증되지 않았다. 결제/사용 한도를 해결한 뒤 다시 실행해야 한다. 로컬 UI, 데모 전체 흐름, 문서 추출, 저장·삭제·내보내기는 검증했다. 상세 증거는 docs/QA.md 참조.

로컬 단일 사용자 출품용 앱이다. 공개 배포용 사용자 인증과 사용자별 과금 제한은 포함하지 않는다. OpenAI 모드는 자료·답변·음성을 OpenAI로 전송하며 API 비용이 발생한다. 서버에 별도 DB나 원본 파일 저장은 하지 않지만, 완료한 자료와 대화는 현재 브라우저 localStorage에 저장된다. 공용 PC에서는 연습 후 기록을 삭제한다. 보고서는 채용 판단이나 실력의 객관적 점수가 아니다.

## 디자인과 라이선스

DESIGN.md, docs/DESIGN-TOOLS.md, THIRD-PARTY.md 참조. Google Stitch를 사용하지 않는다. 개발용 React Grab/React Scan은 `NEXT_PUBLIC_ENABLE_REACT_DEVTOOLS=1`일 때만 활성화되고 프로덕션에서는 포함하지 않는다.

외부 도구 원본과 개발 스킬은 저장소에 포함하지 않는다. 다시 설치할 때는 docs/SKILL-SOURCES.md와 .design-tools/sources.lock.json의 출처를 참조한다.
